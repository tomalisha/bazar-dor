# Bazar-Dor 🛒

Bazar-Dor is a responsive online grocery shopping website designed to help users explore grocery products, browse categories, and manage their accounts.

## Features

- Responsive homepage with a hero banner
- Grocery product cards and product details
- Product category browsing
- User registration and sign-in
- Secure authentication with Better Auth
- User profile and profile name update
- Sign-out functionality
- Database integration for authentication

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Better Auth
- PostgreSQL
- Git and GitHub
- Vercel

## Getting Started

Install the dependencies:

```bash
npm install
```

Create a `.env.local` file and configure the required environment variables:

- `DATABASE_URL`
- `BETTER_AUTH_SECRET`
- `BETTER_AUTH_URL`

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in browser.
